🕘 Verlauf

❓ So kommt die Formel in PowerPoint

Weg 1 · Native Formel (empfohlen)
  1. Hier „Für PowerPoint kopieren“ klicken (kopiert MathML).
  2. In PowerPoint Strg+V auf die Folie → es entsteht eine echte, editierbare Formel.
  3. Falls es als Text landet: Start → Einfügen → Inhalte einfügen → MathML.
Weg 2 · LaTeX direkt (Microsoft 365)
  • „LaTeX mit $$ … $$ kopieren“ → in PowerPoint einfügen: neuere M365-Builds wandeln das automatisch in eine Formel um.
  • Oder in PowerPoint: Alt+= → im Formel-Menüband von Unicode auf {}LaTeX umstellen → Code einfügen → Strg+Alt+= (Konvertieren).
Weg 3 · Als Bild (Fallback)
  • „PNG kopieren“ → einfügen. Skaliert scharf, ist aber kein editierbares Formelobjekt mehr.
📸 Formeln aus Skript / Buch (OCR)
  • Integriert: Screenshot kopieren (Win+Shift+S) → hier Strg+V → „Formel erkennen". Läuft lokal im Browser (TexTeller3); beim ersten Mal lädt er ~250 MB Modell (Internet nötig), danach aus dem Cache.
  • Falls die KI zweifelhafte Ergebnisse liefert (Handschrift, lange mehrzeilige Konstrukte): OpenMathpix (offline, gratis) – LaTeX landet in der Zwischenablage, hier einfach einfügen.
  • Weitere Alternativen: Mathpix Snip (sehr genau, Freemium), mathcheap.xyz, imagetolatex.com (Web).
  • Tipp: Eingefügtes LaTeX mit $…$/$$…$$ wird automatisch bereinigt.
